# Prehab

Persönliche Prehab- und Fitness-App bis zur Hüft-OP.

## v0.1.0

Mobiler PWA-Prototyp für iPhone.

- Dashboard mit Gewicht, Zielgewicht und OP-Countdown
- Training erfassen: Radfahren, Schwimmen, Bänder, Faszienrolle, Dehnen, Tennis
- Trainingsdauer und Intensität dokumentieren
- Gewichtsverlauf lokal speichern
- Statistik und Trainingshistorie
- Offline/lokale Speicherung via `localStorage`
- GitHub Pages Deployment über GitHub Actions

## Auf dem iPhone

Nach erfolgreichem GitHub-Pages-Deployment die Pages-Adresse in Safari öffnen und über **Teilen → Zum Home-Bildschirm** installieren.
